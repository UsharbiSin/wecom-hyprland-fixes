# 升级与故障排查

[返回首页](../../README.md) · [使用说明目录](README.md)

## 升级前后

记录 Wine、企业微信、会议组件版本以及已经启用的模块。
升级后先运行 `doctor`，再按模块验收矩阵测试。
哈希变化时先移除受影响模块，调查上游是否已修复；不要只改白名单。

`Wine 11.18-1` 的 qcap/ntdll 不匹配 `11.17` 摄像头模块的白名单。
构建和安装会拒绝这组组件；该版本是否仍有摄像头故障，需要单独实测。

## 常见情况

| 现象 | 先检查什么 |
| --- | --- |
| 提示目标哈希不同 | 是否升级组件、前缀是否正确、发行版构建是否一致 |
| 提示已有 Wine 进程 | 正常退出旧入口及子进程，避免与现有 wineserver 混用 |
| 构建缺依赖 | 查对应模块依赖，确认编译器架构和开发头文件 |
| 文档仍白屏 | CEF 哈希、WeMail DPI、是否从统一入口重启 |
| 文档容量已满 | 企业文档容量，属于独立问题 |
| 图片仍不能粘贴 | 两个方向分别测试，确认旧全局服务未被启动 |
| WPS 富格式异常 | 检查其他剪贴板管理器，按旧方案迁移说明排除全局接管 |
| 菜单外部项不响应 | 精确焦点规则、旧绑定冲突、当前窗口 class/title |
| 共享只有窗口或黑屏 | Portal 后端、PipeWire、授权对话框和对应会议宿主 |
| 无法过滤会议窗口 | 尚未实现会议窗口排除能力 |
| Thunar 没有打开 | 桥接器、队列权限、路径形式和对应 Explorer 位数 |
| 回滚拒绝覆盖 | 对照备份判断后续变更，勿删除状态目录 |

## 缩小故障范围

排查时记录以下信息，方便区分版本问题、配置问题和操作差异：

- 发行版、Wine、企业微信、内置会议及桌面版本。
- 出错模块、执行的命令和完整错误提示。
- 图片或文件类型、操作方向、预期结果与实际结果。
- 问题是否在重启后仍出现，移除对应模块后是否恢复。

图片输入和输出应分别测试；构建成功与应用实际显示图片是不同检查。
