## 如何阅读

表中的实际效果来自指定版本与桌面环境。

选择模块时应同时核对组件版本、哈希和验证范围。

## 检查已安装模块

```sh
./wecom-fix doctor --prefix "$WECOM_PREFIX"
```

该命令核对安装记录、产物哈希和目标组件版本。
检查通过表示文件与记录一致，仍需按对应功能说明确认实际界面行为。

本工具面向 Linux Wine 环境；这些结果不代表原生 Windows 平台兼容。

## 隔离安装验证：2026-09-28

在全新 Wine 前缀与独立 XDG 数据目录中，`display` 模块的
构建、安装、检查和移除均已通过。
两处 DPI 原值分别为 144/120，安装后均为 96，移除后恢复为 144/120。
缺失注册表键和值均正确识别为空，临时 Wine 服务正常退出。

32 位会议兼容库已在独立前缀通过加载、导出和错误返回检查。
这些验证不包含实际入会或会议控件操作。

## 安装后的功能验收

按对应功能文档逐项检查：

1. 完成所需操作，例如打开文档、粘贴图片或共享屏幕。
2. 正常退出企业微信，确认辅助程序和采集会话结束。
3. 按回滚说明移除模块，确认原配置恢复。
4. Wine、企业微信或桌面组件升级后，重新检查受影响功能。
