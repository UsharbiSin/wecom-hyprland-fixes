## 检查已安装模块

```sh
./wecom-fix doctor --prefix "$WECOM_PREFIX"
```

该命令核对安装记录、产物哈希和目标组件版本。
如已安装 `copyq`，也会核对 CopyQ 原生规则；
不带 `--prefix` 时仅检查用户桌面级 CopyQ 模块。
检查通过表示文件与记录一致，仍需按对应功能说明确认实际界面行为。

本工具面向 Linux Wine 环境；这些结果不代表原生 Windows 平台兼容。

## 文档中文输入验证：2026-09-28

环境为 Arch Linux、Wine `11.18-1`、Hyprland `0.56.2`、XWayland，
企业微信 `5.0.11.6018`，Fcitx5 `5.1.23` 配合 Rime。
使用单显示器，Wine 为 96 DPI，桌面缩放为 125%。
正式构建产物在真实 CEF 评论草稿中完成中文输入验证；
检查没有发送评论，也没有编辑正文。

最新 v2 模块还完成以下候选位置和切换对照：

- 候选从旧聊天位置移动到当前评论插入点。
- 提交「你」后继续输入，候选跟随新的插入点向右移动。
- 保持 `hao` 候选打开，将主窗口向右移动 200、向下移动 125 个物理像素，
  实际界面中的候选跟随移动；恢复窗口后候选也回到原位。
- 切回普通聊天，原生候选位置正确，「你」可以提交到聊天草稿；
  清除测试文字后返回文档，候选位置仍正确。
- 连续两次停止均成功，源端和目标端的 v2 接收窗口属性均已清除。
- 再次启动 v2 后，实际界面确认「你好」进入评论草稿，随后清除测试文字。
- 本机既有启动器加载私有 v2 产物，关闭调试日志后，`ni` 候选位置仍正确。

这些结果覆盖指定缩放下的实际输入、候选跟随、聊天切换和停止清理。
它们不证明正文保存、协同同步、表格或其他文档控件已经正常。

## 安装后的功能验收

按对应功能文档逐项检查：

1. 完成所需操作，例如打开文档、粘贴图片或共享屏幕。
2. 正常退出企业微信，确认辅助程序和采集会话结束。
3. 按回滚说明移除模块，确认原配置恢复。
4. Wine、企业微信或桌面组件升级后，重新检查受影响功能。
