## 如何阅读

## 检查已安装模块

```sh
./wecom-fix doctor --prefix "$WECOM_PREFIX"
```

该命令核对安装记录、产物哈希和目标组件版本。
检查通过表示文件与记录一致，仍需按对应功能说明确认实际界面行为。

本工具面向 Linux Wine 环境；这些结果不代表原生 Windows 平台兼容。

这些验证不包含实际入会或会议控件操作。

## 文档中文输入验证：2026-09-28

环境为 Arch Linux、Wine `11.18-1`、Hyprland `0.56.2`、XWayland，
企业微信 `5.0.11.6018`，Fcitx5 `5.1.23` 配合 Rime。
`docs-ime` 正式构建产物在真实 CEF 评论草稿中输入「你好」成功。
检查没有发送评论，也没有编辑正文。

连续两次停止均成功；停用后选择 `ni` 候选没有新增中文，
再次启动同一产物后「你」正常进入草稿。
普通聊天中文输入也通过对照，所有测试草稿已清除；
本机私有目录中的相同构建产物再次通过评论草稿输入。
此处验证的是真实应用中的输入与启停，未覆盖正文保存和协同同步。

32 位严格构建及新增 10 项离线测试通过。
离线检查覆盖报文截断与溢出、上下文边界、焦点及进程关系、
未知哈希和错误版本拒绝，以及优化模式下的构建保护和启动时必需环境变量。
完整 `python3 tools/check.py` 共 57 项测试，56 项通过，1 项跳过；
跳过项是需设置 `WECOM_TEST_NATIVE=1` 的会议隔离 Wine 测试。
独立跨进程编辑框复现器仅完成编译，不能替代真实应用输入验证。

本次候选仍位于旧聊天区域；原始预编辑光标和分句属性不保留。
未验证其他输入法、表格、多显示器和不同缩放。
操作与完整边界见[共享文档中文输入](features/docs-ime.md)。

## 安装后的功能验收

按对应功能文档逐项检查：

1. 完成所需操作，例如打开文档、粘贴图片或共享屏幕。
2. 正常退出企业微信，确认辅助程序和采集会话结束。
3. 按回滚说明移除模块，确认原配置恢复。
4. Wine、企业微信或桌面组件升级后，重新检查受影响功能。
